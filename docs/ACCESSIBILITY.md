# Accessibility notes

The shell uses landmark navigation, visible labels, keyboard-operable native controls, focus rings, responsive reflow, and reduced-motion overrides. Editors identify their editable region as a multiline textbox. Validation is displayed adjacent to its field.

Before release, run automated axe checks and manual WCAG 2.2 AA checks at 200% zoom, in high contrast, with keyboard only, and with VoiceOver/NVDA. Canvas projects require meaningful project names and text-layer alternatives; exported media requires alt text and video captions before approval.
